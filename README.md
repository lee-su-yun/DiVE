# DiVE project page

Project page for **Learning Decomposed Visibility for Efficient Active Exploration of
Cluttered Scenes** (CoRL 2026).

Built on the [Nerfies](https://github.com/nerfies/nerfies.github.io) project page template,
licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

## Local preview

```bash
python -m http.server 8000
# open http://localhost:8000
```

## Layout

- `index.html` — the whole page
- `static/images/` — figures exported from the paper PDF
- `static/DiVE_paper.pdf` — camera-ready paper
- `static/css`, `static/js` — Bulma + template assets

## Deploy

Pushed to a GitHub repository with GitHub Pages enabled (Settings → Pages → Branch: `main`, `/root`).
